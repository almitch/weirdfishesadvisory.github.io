# weirdfishesadvisory.github.io
Public repo for my public website. Single-page Jekyll site on GitHub Pages. The page is a dive from the surface to the abyss. Content lives in `_data/work.yml`, `_data/services.yml` and `_includes/sections/`; motion is GSAP + ScrollTrigger from cdnjs. Type is Gloock (titles) and Epilogue (body), both from Google Fonts. `assets/fonts/` is gitignored because it holds an old personal-use-only font. Built with the help of Claude.
